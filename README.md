
# Seasonal Hydrodynamic Niche Selection by Whale Sharks

This repository contains the code and data supporting the study of seasonal hydrodynamic niche selection by whale sharks (*Rhincodon typus*) in Bahía de La Paz, Gulf of California, Mexico.

## Contents
- `data/`: Data used in the analyses.
- `scripts/`: R scripts for data processing, statistical analyses, and figures.


## Data availability
Data sources: whale shark occurrence data: www.gbif.org. Oceanographic data: https://marine.copernicus.eu/

## Software
Analyses were conducted using R.
